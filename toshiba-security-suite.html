Enterprise Data visualization UX
Aug 2024 – May 2025

ELERA Security Suite

Toshiba Global Commerce builds retail platforms that operate at massive scale. I led UX for the ELERA Security Suite data visualization dashboard—helping loss-prevention and operations teams monitor activity across an AI-enabled retail stack that processes 25M+ transactions per year.

How might we
Turn high-volume transactional and security signals into a clear, scannable dashboard so teams can spot risk, drill into detail, and act without drowning in noise?
Role
UX Designer
Tools
Figma, Miro, workshops
Team
PM, engineering, stakeholders
Toshiba Commerce
CONTEXT

Security at retail scale

Operators need a single place to understand what is happening across stores and channels: anomalies, policy events, and trends over time. The product had to support dense data, role-based mental models, and fast drill-downs while staying consistent with the broader ELERA ecosystem.

Users & jobs-to-be-done

Clarify who consumes each view (executive summary vs. analyst workflow), what decisions they make in-session, and which exports or handoffs they rely on downstream.

Constraints

Enterprise patterns, accessibility, performance with large datasets, and alignment with existing ELERA UI conventions—without sacrificing scanability for specialized security tasks.

PROCESS

From signals to stories

I partnered with product and engineering to map data relationships, prioritize views by decision frequency, and iterate on chart types, density, and interaction patterns. Workshops and critique cycles kept technical feasibility and user language aligned.

1. Frame the narrative

Defined the hierarchy of metrics and time ranges so the default landing state answers “what changed and why should I care?” before users filter.

2. Visualization + density

Balanced chart legibility with enterprise data volume—legends, states, empty and error patterns, and consistent color semantics for risk.

3. Handoff

Documented responsive behavior, component specs, and edge cases so engineering could ship predictably across dashboard modules.
